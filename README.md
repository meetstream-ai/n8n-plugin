# MeetStream n8n Plugin

n8n plugin for building workflow automations with MeetStream meeting bots, recordings, transcripts, and meeting data.

## Status

This repository is being initialized. Implementation details, setup instructions, and usage examples will be added as the plugin is built out.

## About MeetStream

MeetStream provides meeting bot infrastructure for joining online meetings, recording calls, generating transcripts, and extracting structured meeting data through developer-friendly APIs.

## Repository Scope

- n8n nodes for common MeetStream API workflows.
- Example workflow templates for meeting capture and post-meeting automation.
- Documentation for installation, credentials, triggers, actions, and publishing once available.
